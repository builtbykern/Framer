# Sill styles (create in Framer Assets first)

## Colors
- Paper: #F4F3F0
- Ink: #000000
- Ink muted (optional): #6B6B6B for link labels only if needed

## Text styles (one grotesk family — Inter/Geist/System OK if already in project; prefer a single loaded grotesk)
1. Sill/Name — 12–14px, all caps, light/regular, tracking slight, color Ink
2. Sill/Line — 28–36px, sentence case, medium/bold, tight leading, color Ink
3. Sill/List — 16–18px, medium, color Ink (numbers 01–06 same style)
4. Sill/ListMute — optional 12px for secondary URL line (Soulmates skin only)

## Spacing (document, apply as stack gaps)
- Page inset: 48–64px desktop
- Name → Line: 24–32px
- Line → List: 48–64px
- List row gap: 12–16px
- Split: 50/50

Create these in Framer Styles / Color styles BEFORE composing frames.
